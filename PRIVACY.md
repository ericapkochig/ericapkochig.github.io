# Privacy Policy

## Entities

`[Website]`: The website accessed at [ericapkochig.github.io](https://ericapkochig.github.io/)

`[Third-Party]`: Other providers which the `[Website]` relies upon to work

`[User]`: The user connecting to the `[Website]`

## Data Collection

* **IP Address** by `[Website]`'s host -- See details below

The `[Website]` does **not** collect any Personal Identifyable Information (PII) about the `[User]`.

The `[Website]` is being hosted by [Github](https://github.com) (`[Third-Party]`), and **they** will collect the `[User]`'s **IP Address**.  
This is required in order for the `[Website]` to function.


> "When a GitHub Pages site is visited, the visitor's IP address is logged and stored for security purposes, regardless of whether the visitor has signed into GitHub or not. For more information about GitHub's security practices, see [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement)."  
> \- Source [Github Pages Documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection)

## Cookies

The `[Website]` does **not** utilize cookies.
